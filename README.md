# Диплом. Задание №1: Юнит-тесты

## Описание дипломного проекта

**Stellar Burgers** — это сервис, позволяющий собрать и заказать бургер из необычных ингредиентов.

В рамках дипломного проекта необходимо покрыть юнит-тестами класс `Burger`.

Процент покрытия 100% (отчет: `htmlcov/index.html`)

### Структура репозитория с дипломным проектом

- `praktikum` - пакет, содержащий код программы
- `tests` - пакет, содержащий юнит-тесты `test_burger.py` класса `Burger`, а также фикстуры и хелперы
- `data` - тестовые данные

### Запуск автотестов

#### **Установка зависимостей**

> `pip install -r requirements.txt`

#### **Запуск автотестов и создание HTML-отчета о покрытии**

> `pytest --cov=praktikum --cov-report=html`
